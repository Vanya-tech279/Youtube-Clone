# YouTube Clone

A **fully functional YouTube-like web application** built using **HTML, CSS, and JavaScript**.  
This project replicates the core interface and features of YouTube, with responsive design, video browsing, search, categories, and dark mode.

---

## 🔹 Features

- Responsive video grid layout with thumbnails, titles, views, and duration  
- Search functionality to filter videos by title  
- Category filters for Web Development, AI, Music, Gaming, etc.  
- Dark mode toggle for better user experience  
- Video modal player for watching videos directly on the page  
- Smooth animations and hover effects  
- Lazy loading of videos as you scroll  

---

## 💻 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Icons:** Font Awesome  
- **Video Data:** Mock dataset with embedded YouTube links
